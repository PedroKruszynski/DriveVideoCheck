Drive Video Check

Instalação:
1. Extraia este ZIP.
2. Abra chrome://extensions.
3. Ative Modo do desenvolvedor.
5. Clique em "Carregar sem compactação" e selecione a pasta DriveVideoCheck.
6. Recarregue o Google Drive.

Uso:
- Clique nos três pontinhos de uma linha de vídeo.
- A opção "Marcar como assistido" deve aparecer no final do menu.
- O estado fica salvo localmente pelo ID do arquivo.

Observações:
- Esta é uma integração visual com o menu do Drive, não uma opção oficial do Google.
- O HTML interno do Drive pode mudar; se a opção não aparecer, precisamos inspecionar o menu aberto e ajustar o seletor.
